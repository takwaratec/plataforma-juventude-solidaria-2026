# 🌱 Plataforma Juventude Solidária — Ciclo 2026

## 🧭 O que é este repositório?

Aqui fica a documentação do projeto **Viveiro-Educador de Mudas Terra Viva**, 
submetido ao edital **Juventude Solidária 01/2026** para o 
**Assentamento Mário Lago** (Ribeirão Preto/SP).

**👥 Para quem?** Membros do MST, comunidade do Mário Lago e apoiadores.
A linguagem aqui é simples e direta.

---

## 🌐 Acessar documentos

### Pelo site (mais fácil)
👉 **https://takwaratec.github.io/plataforma-juventude-solidaria-2026/**

No site você encontra:
- 📄 **Território** — mapa e dados do Mário Lago
- 📄 **Projetos** — Viveiro-Educador, Biofábricas, Bambu
- 📄 **Documentos do Projeto** — atas, formulários, relatórios
- 📄 **Documentos Administrativos** — estatuto, atas de fundação
- 📄 **Editais** — formulários e gabaritos para download (.md)

### Pelo GitHub (para baixar arquivos)
Para baixar um arquivo direto do repositório:
1. Entre na pasta desejada (ex: `02_PROPOSTAS/`)
2. Clique no arquivo (ex: `PROPOSTA_FINAL_VIVEIRO_EDUCADOR_TERRA_VIVA.md`)
3. Clique no botão **"Raw"** (canto superior direito)
4. Salve a página (Ctrl+S ou Cmd+S)
