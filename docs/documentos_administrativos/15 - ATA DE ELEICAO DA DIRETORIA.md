|                                                                                                                                                                                                                                                                                                              |
| *Este modelo de **Ata de Eleição e Posse** destina-se exclusivamente à renovação de cargos após o término do **mandato da gestão anterior (definida na Ata de Fundação ou eleição subsequente)**.*                                                                                                           |
|                                                                                                                                                                                                                                                                                                              |
| ***Antes de utilizar este modelo, certifique-se de que:***                                                                                                                                                                                                                                                   |
|                                                                                                                                                                                                                                                                                                              |
| 1.  *O período do mandato atual, conforme estabelecido no seu Estatuto Social, chegou ao fim.*                                                                                                                                                                                                               |
|                                                                                                                                                                                                                                                                                                              |
| 2.  *A nova eleição está ocorrendo dentro do prazo de transição previsto, para evitar irregularidades burocráticas ou descontinuidade administrativa.*                                                                                                                                                       |
|                                                                                                                                                                                                                                                                                                              |
| *Caso a gestão vigente ainda seja a que foi eleita na Assembleia de Fundação da Entidade, apresente na Plataforma a "ATA DE FUNDAÇÃO E CONSTITUIÇÃO DA ENTIDADE", modelo disponível [[aqui.]{.underline}](https://docs.google.com/document/d/1n-uAArtFT887Kmam4VIg48hBBkqvJ_3KgPtdTfAvasU/edit?usp=sharing)* |
